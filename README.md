# 个人作品集

这是一个用于保存和持续整理“个人作品集”项目的 GitHub 仓库。

## 用途

- 保存作品集项目文件
- 记录 Codex 协助完成的修改
- 留存关键提示词和项目决策
- 方便后续继续开发、回滚和展示

## 推荐工作流

1. 在本地完成一次明确修改。
2. 更新 `docs/log.md`，记录本次做了什么、为什么做。
3. 如有重要提示词，更新 `docs/prompts.md`。
4. 使用 Git 提交本次修改。
5. 推送到 GitHub 作为长期项目记录。

## 目录

```text

  log.md
  prompts.md
  decisions.md
src/
assets/
```
